# `/bff/` is een backend-for-frontend: hij bestaat om precies een schermpje
# te vullen en verandert wanneer dat schermpje verandert. Geen contract,
# geen versiebelofte, geen changelog, geen toezegging over beschikbaarheid
# voor derden. Wat je daar zou willen halen, staat ook in een gepubliceerde
# API met OpenAPI-spec — meestal Ontsluiten v2. Zie het api-register.
#
# De uitsluiting van `/bff/` was al beleid op deze host voordat dit bestand
# werd uitgebreid; ze is hier alleen toegelicht en herhaald in de tweede
# groep. Dat herhalen is nodig: een robot volgt precies een groep — de
# meest specifieke die op zijn naam past — en erft niets van de andere.
#
# Het gerenderde omgevingsdocument is een projectie. Wil je weten wat de
# regel zegt, bevraag dan Presenteren v8 en lees de annotaties, niet de
# HTML en niet de PDF-bijlage.
#
# Werk je namens iemand met een eigen API-sleutel, dan ben je in de zin van
# dit bestand geen crawler maar een client; deze regels gaan over
# ongeauthenticeerd ophalen. Volg /llms.txt.

# WAT DE DISALLOW HIER WEL EN NIET ZEGT. Het hele `/publiek/`-oppervlak
# vereist een API-sleutel; zonder sleutel krijg je overal 401. Deze regels
# gaan dus niet over toegang maar over crawlen: welke paden het zinvol is
# om als bezoekende robot op te halen.
#
# De Downloaden-API (Ozon Download) is uitgesloten omdat het geen crawlbare
# bron is. Het is een opdracht-API: je vraagt een pakket aan, wacht tot het
# gebouwd is en haalt het daarna op. Er zijn geen URL's om te volgen en er
# valt niets te indexeren; een crawler haalt er alleen 401's op. Voor een
# geregistreerde client met een sleutel is het wel degelijk de juiste route
# om een volledig document op te halen — robots.txt kan dat onderscheid
# niet uitdrukken, /llms.txt wel.
#
# Er is geen aparte User-agent-groep voor bulkclients: de standaard kent
# geen wildcard binnen een naam, dus een groep als `*-sync` matcht niets.
# Het onderscheid loopt via de API-sleutel. Vraag er een aan via het
# api-register, identificeer je met een User-Agent van de vorm
#     <naam>/<versie> (+https://<project-url>; <contactadres>)
# en houd het budget uit /llms.txt aan in plaats van de Crawl-delay.
